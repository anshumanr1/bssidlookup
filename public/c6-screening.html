C6 location screening

Checks whether a C6’s recorded location agrees with what its radio link reports. Test one C6 by hand, or screen many at once from a CSV export. C6s that fail go to Multi-A6 trilateration.

Link under test

Recorded location = the latitude/longitude currently tagged to this C6 in our database (geocoded address). Coordinates in decimal degrees.

What this test checks

The A6 measures how far away each C6 is, using the signal’s round-trip time (ranging). The NMS shows this as link distance. If the measured distance doesn’t match the distance from the A6 to the recorded location, the recorded location is probably wrong.

Recorded distance = great-circle distance (A6 → recorded location) Gap = | measured − recorded | Allowed gap = max(absolute tolerance, relative tolerance × measured) Fail if Gap > Allowed gap

This is the cleanest of the three tests: ranging is not affected by interference or obstructions the way signal level is.

Result

Rough position uses the measured distance along the per-client beam angle if given (Sector tab), otherwise along the sector centre. With only the sector known it is a coarse estimate.

What this test checks

Each A6 sector points in one direction (azimuth, degrees clockwise from north) and covers a fan of angles (horizontal beamwidth). A C6 served by that sector should lie inside the fan. If the recorded location is outside it, either the location or the sector mapping is wrong, even when the distance looks right.

Bearing = direction from A6 to recorded location Offset = Bearing − Sector azimuth (−180° … +180°) Fail if |Offset| > beamwidth ÷ 2 + edge margin

If the radio reports a per-client beam angle, the test also compares the bearing with that angle. This check is much tighter than the sector fan.

Result

What this test checks

From the recorded distance we can predict the signal level the C6 should receive in free space, then compare it with the measured level.

FSPL (dB) = 20·log10(d km) + 20·log10(f MHz) + 32.44 (ITU-R P.525) Expected RSSI = Tx power + A6 gain + C6 gain − losses − FSPL Difference = Measured − Expected

Stronger than expected is a strong flag: obstructions can only weaken a signal, so the C6 is probably closer than recorded. Weaker than expected is only a watch flag, because interference, obstruction or misalignment can also cause it.

Result

Free space is a best case: real links lose more. That is why the deficit threshold is wider than the surplus threshold.
