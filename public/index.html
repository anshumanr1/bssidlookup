Location Tools

POC tools for locating AirFiber subscribers and checking C6 locations.

BSSID lookup

BSSID Locator → Look up one router BSSID in Apple, then confirm with Google using its nearest neighbours. Single BSSID BSSID Batch Locator → Run a list of BSSIDs through Apple and Google, with hit rates and a results CSV. Batch

C6 radio checks

C6 Location Screening → Check whether a C6’s recorded location agrees with its radio link: distance, sector and path-loss tests. Single or batch CSV Multi-A6 Trilateration → Estimate where a suspect C6 really is from the signal levels it hears from several A6s. Single or batch CSV
